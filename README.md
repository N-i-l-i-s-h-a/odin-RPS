# Odin-RPS

## Overview

Odin-RPS is a Rock-Paper-Scissors game built as part of The Odin Project curriculum. The application lets two players play the classic hand-gesture game by selecting rock, paper, or scissors and seeing the results in real time. It is implemented using HTML, CSS, and JavaScript and runs in the browser.

## Features

- Players can choose between rock, paper, or scissors  
- The game determines the winner or indicates a draw after each round  
- Score tracking across multiple rounds  
- Reset option to start a new game and clear scores  
- Simple user interface designed for clarity
